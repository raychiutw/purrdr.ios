Purrdr 主機服務

主機服務讓 Purrdr 以 HTTPS 連到你的電腦，不需要在電腦上開 SSH。它只在電腦本機(127.0.0.1)接受連線，由 Tailscale 的 tailscale serve 提供只在你的 tailnet 內連得到的 HTTPS 位址;憑證與加密都由 Tailscale 處理，不經過 Purrdr 的伺服器。

需要準備什麼?

  • macOS(Apple 晶片或 Intel)、Linux(x86_64 或 ARM64)或 Windows(x86_64)。
  • 電腦上執行著 herdr 0.9.5 以上。
  • 電腦與 iPhone／iPad 都安裝 Tailscale 並登入同一個 tailnet。
  • 在 Tailscale 管理主控台的 DNS 頁開啟 MagicDNS 與 HTTPS Certificates。

開啟 HTTPS Certificates 後，電腦的名稱(例如 studio.tail1234.ts.net)會寫進公開的 Certificate Transparency 紀錄。名稱含有不想公開的資訊時，先在 Tailscale 改名。安裝程式也會提醒並徵求你同意。

安裝

在電腦上開終端機，執行一行指令(不需要 sudo 或系統管理員):

macOS、Linux

curl -fsSL https://github.com/raychiutw/purrdr.ios/releases/latest/download/install.sh | sh

Windows(PowerShell)

irm https://github.com/raychiutw/purrdr.ios/releases/latest/download/install.ps1 | iex

指令會下載這台電腦適用的版本，以 SHA-256 檢查碼驗證(不符就停止、不留下檔案),再執行 purrdr-host-service install:檢查 Tailscale 設定、把程式放到 ~/.purrdr/host-service/、設定 tailscale serve,並在登入後自動啟動(macOS 是 LaunchAgent,Linux 是 systemd user service,Windows 是登入時執行)。

macOS 版經過 Apple 公證。Windows 版沒有程式碼簽章，Windows 可能顯示 SmartScreen 警告。

要指定埠或 herdr 的具名 session:macOS／Linux 用 curl -fsSL …/install.sh | sh -s -- --port 47820 --session work;Windows 用 & ([scriptblock]::Create((irm …/install.ps1))) --port 47820 --session work。要安裝特定版本，先設環境變數 PURRDR_HOST_SERVICE_VERSION(例如 0.1.0)。

也可以從 GitHub Releases 手動下載壓縮檔(附 SHA256SUMS),解壓後執行 purrdr-host-service install。

配對 iPhone／iPad

  1. 在電腦上執行 purrdr-host-service pair(macOS／Linux 的程式在 ~/.purrdr/host-service/bin/)。畫面會顯示 QR code、HTTPS 位址與一次性配對碼。
  2. 用 iPhone 的「相機」App 掃 QR code,或在 Purrdr 的「⋯ → Hosts → +」選 HTTPS,輸入位址與配對碼。
  3. 只想讓這支裝置看、不能操作：改用 purrdr-host-service pair --read-only。

列出已配對的裝置：purrdr-host-service devices;撤銷一支裝置：purrdr-host-service revoke <裝置 ID>。在 Purrdr 刪除這台主機時，也會撤銷這支裝置。

更新

再執行一次上面的安裝指令就是更新，已配對的裝置會保留。Purrdr 發現主機服務比它知道的版本舊時，會在主機清單提示更新並附上指令。

查看狀態與解除安裝

  • 狀態：purrdr-host-service status(是否安裝、HTTPS 位址、herdr 是否在執行)。
  • 解除安裝：purrdr-host-service uninstall。會停止自動啟動、移除 tailscale serve 設定與 ~/.purrdr/host-service/,電腦回到安裝前的狀態。

透過 HTTPS 能做什麼?

Agent 列表、聊天、送出 prompt、回答「需要你」與 Pane 終端機都可以用。登入 Shell 與檔案目前只有 SSH 連線方式提供。

Purrdr Host Service

The host service lets Purrdr connect to your computer over HTTPS, with no SSH server needed. It only accepts connections on the computer itself (127.0.0.1); Tailscale’s tailscale serve gives it an HTTPS address that’s reachable only inside your tailnet. Tailscale handles the certificate and encryption, and nothing goes through Purrdr’s servers.

What do I need?

  • macOS (Apple silicon or Intel), Linux (x86_64 or ARM64), or Windows (x86_64).
  • herdr 0.9.5 or later running on the computer.
  • Tailscale on both the computer and your iPhone or iPad, signed in to the same tailnet.
  • MagicDNS and HTTPS Certificates turned on in the DNS page of the Tailscale admin console.

With HTTPS Certificates on, the computer’s name (like studio.tail1234.ts.net) is written to public Certificate Transparency logs. If the name contains anything you’d rather keep private, rename the machine in Tailscale first. The installer reminds you and asks before continuing.

Installing

Open a terminal on the computer and run one command (no sudo or administrator needed):

macOS, Linux

curl -fsSL https://github.com/raychiutw/purrdr.ios/releases/latest/download/install.sh | sh

Windows (PowerShell)

irm https://github.com/raychiutw/purrdr.ios/releases/latest/download/install.ps1 | iex

The command downloads the build for this computer, verifies its SHA-256 checksum (stopping without leaving files behind if it doesn’t match), and runs purrdr-host-service install, which checks your Tailscale settings, puts the program in ~/.purrdr/host-service/, sets up tailscale serve, and starts it when you sign in (a LaunchAgent on macOS, a systemd user service on Linux, a sign-in entry on Windows).

The macOS build is notarized by Apple. The Windows build isn’t code-signed, so Windows may show a SmartScreen warning.

To choose a port or a named herdr session: on macOS and Linux, curl -fsSL …/install.sh | sh -s -- --port 47820 --session work; on Windows, & ([scriptblock]::Create((irm …/install.ps1))) --port 47820 --session work. To install a specific version, set PURRDR_HOST_SERVICE_VERSION (for example 0.1.0) first.

You can also download an archive from GitHub Releases (with SHA256SUMS), extract it, and run purrdr-host-service install.

Pairing your iPhone or iPad

  1. On the computer, run purrdr-host-service pair (on macOS and Linux the program is in ~/.purrdr/host-service/bin/). It shows a QR code, the HTTPS address, and a one-time pairing code.
  2. Scan the QR code with the iPhone Camera app, or in Purrdr go to “⋯ → Hosts → +”, choose HTTPS, and enter the address and pairing code.
  3. For a device that can watch but not act, use purrdr-host-service pair --read-only instead.

List paired devices with purrdr-host-service devices; revoke one with purrdr-host-service revoke <device ID>. Deleting the host in Purrdr also revokes that device.

Updating

Run the install command again to update. Paired devices stay paired. When Purrdr sees a host service older than the version it knows about, it shows an update notice with the command in the host list.

Status and uninstalling

  • Status: purrdr-host-service status (whether it’s installed, its HTTPS address, and whether herdr is running).
  • Uninstall: purrdr-host-service uninstall. It stops the sign-in start, removes the tailscale serve setting and ~/.purrdr/host-service/, and leaves the computer as it was before installing.

What works over HTTPS?

The Agent list, chats, sending prompts, answering “Needs You”, and Pane terminals all work. Login Shell and Files are currently available only with SSH.
