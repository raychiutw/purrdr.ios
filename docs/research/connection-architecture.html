③-1 Allymote 伺服器 ↔ herdr（細節）

直接連 herdr 官方本機 socket，每個請求開一條新連線；不用 remote-api-bridge，執行期間不呼叫 herdr CLI

狀態

每秒輪詢 session.snapshot；沒有用 events.subscribe。

對話內容

依 snapshot 的 agent_session 定位檔案，自己讀 ~/.claude/projects、~/.codex/sessions 的 jsonl，每 500 ms 檢查。

輸入

pane.send_text、pane.send_keys。

終端機

不是 PTY，也不是 terminal session control；每 150 ms 用 pane.read 讀整個畫面（ANSI）推給手機。

integration install

只裝官方 SessionStart hook，呼叫 herdr pane report-agent-session 告訴 herdr session id 與紀錄路徑；不回報狀態、不提供對話。

Purrdr host agent 建議

同樣直連 socket，但狀態改用 events.subscribe + snapshot 對帳、送 prompt 用 agent.prompt、終端機維持 ADR-0005 的 terminal session control。

來源：docs/research/allymote-herdr-communication.md（herdr 官方文件為主；Allymote 部分來自使用者授權閱讀的散布檔，Purrdr 實作不依賴）。
