# 品牌色用接近 Apple Music 的紅，但拆成裝飾、紅字、紅底以符合對比

> **已被 ADR-0011 取代**(2026-11-19):主色改翡翠綠，紅字／紅底兩組合併成主色 `AccentColor` 與 `onAccent`。

使用者指定品牌色要接近 Apple Music 的紅(`#FA2D48`)。這個紅配白字只有 3.8:1,低於 HIG 對文字 4.5:1 的要求，所以拆開:`#FA2D48` 只用在圖示與不承載文字的裝飾;承載文字的紅分成兩個角色(#70),各有 light／dark／兩種高對比四個值，色相與飽和度同 `#FA2D48`、只調明度:

- **紅字** `brandText`(文字與 tint,`AccentColor` 同值):`#D80521`／`#FC5D72`／`#A20419`／`#FCA1AD`,對主要、grouped 與卡片背景一般 ≥ 4.5:1、高對比 ≥ 7:1。
- **紅底** `brandFill`(承載白字的填色):一般 `#EA0826`(白字 4.6:1)、高對比 `#B3041B`(7.1:1),深淺色同值。

原本紅字與紅底共用 `#D91E36`／`#FF4D63`,但深色紅字要更亮才對深灰背景達標，紅底卻要更深才能讓白字達標(`#FF4D63` 配白字只有 3.2:1),一個值做不到，所以拆成兩個角色。App 圖示採淺底、只有領頭羊是紅色的 B1,不採紅漸層底配白色圖形的 B2,因為後者跟 Apple Music 圖示的構成太像。

## Consequences

- 紅色在 iOS 常代表危險，所以「需要你」狀態一律附 `!` 符號與文字;真正的錯誤與刪除用系統紅與 destructive role,不用品牌紅。
- 之後有人想「把按鈕改回 `#FA2D48` 比較鮮豔」時，答案是不行，除非按鈕不放白字。
