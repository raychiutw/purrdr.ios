# Triage Labels

各 skill 用五種標準 triage 角色描述 issue 狀態。這份文件把角色對應到本 repo issue tracker 實際使用的 label 名稱。

| mattpocock/skills 的 label | 本 repo 的 label | 意義 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 維護者需要評估這個 issue |
| `needs-info` | `needs-info` | 等回報者補充資訊 |
| `ready-for-agent` | `ready-for-agent` | 規格完整，可以交給 AFK agent 實作 |
| `ready-for-human` | `ready-for-human` | 需要人來實作 |
| `wontfix` | `wontfix` | 不處理 |

skill 提到某個角色時(例如「套上 AFK-ready 的 triage label」),就用上表對應的 label 名稱。

要改用別的名稱時，直接改「本 repo 的 label」那一欄。
