## 結論（2026-11-20，使用者選定）

| 票 | 選定 | 要點 |
|---|---|---|
| #300 送出可撤回 | **B 訊息泡泡就地倒數** | 訊息先以虛線、半透明泡泡出現在對話最下面，泡泡下方「N 秒後送出 · 撤回 · 立即送出」；倒數結束變實心。 |
| #301 離線佇列 | **B 泡泡上標「排隊中」** | 排隊訊息直接在對話裡，帶時鐘與「排隊中」，左滑或長按取消；沒送出的泡泡紅框、下方「放回輸入框」「刪除」與原因。 |
| #302 機密偵測 | **B 底部說明 sheet** | 按送出才檢查；sheet 逐項列出類別與第幾行（不顯示內容），說明只在本機檢查；「返回編輯」（主要）／「仍要送出」。 |
| #305 Send When Done | **B 輸入列「做完再送」開關** | 輸入列工具列有「做完再送」膠囊，開著時送出進佇列；佇列以編號虛線泡泡顯示在對話最下面（分隔線「做完後依序送出」），點泡泡可編輯、刪除；暫停原因在泡泡上方。SSH 主機膠囊停用並說明需要主機服務。 |
| #306 Claude 權限模式 | **B 修正（定案）** | 輸入列工具列、附加鈕右邊的膠囊。**高度與附加鈕相同（34pt），底色與附加鈕相同，文字是一般文字色；只有「略過權限」用紅字。** 點一下切下一個，長按開選單（一般／接受編輯／Plan／略過權限）。切換失敗以提示說明、可再試。 |
| #307 context 與待辦 | **列表 A＋聊天底部 sheet（定案）** | 列表：時間下方小圓環＋百分比（70% 起橙、85% 起紅），第二行尾「☑ 3/7」。聊天：點標題**由下方升起 sheet**，上方是 C 的 context 數字與條，下方是 B 的待辦清單，**已完成（打勾、刪除線）與未完成（空框，進行中綠框）都列出**。 |
| #308 離開期間摘要 | **C 聊天裡的分隔線** | 列表列上加「離開期間 +N 輪」徽章；聊天內離開期間開頭一條分隔線「你離開期間 · N 輪 · 工作 M 分鐘」，可收合那段。 |
| #309 續接歷史 session | **待選（第 2 版）** | 第 1 版看不出「全新聊天」與「續接」的差別，退回重畫。第 2 版三案都並排畫兩種狀態：A 先選要做哪一種、B 新的聊天為主＋續接卡、C 清單第一列就是「新的聊天」。 |
| #310 變更頁 | **A 清單 → 單檔 diff** | 變更清單（狀態、+/−）推入單檔 diff，點行號選行寫評論，底部固定「送出 N 則評論」。 |
| #313 選擇控制 | **待選（第 2 版）** | 使用者：「重新參考 Apple HIG，盡量優先攤開」。第 2 版：A HIG 規則、主機仍用選單；B 連主機也攤開成膠囊列；C 攤開＋「新增聊天」改常駐撰寫鈕、主機用半高 sheet。 |
| #295 未配對主機通知列 | **B 開關停用＋整列可點** | 開關照樣顯示但停用，副標「先配對這台主機 ›」（綠字），點整列開配對流程。 |

## 另外的決定：Agents 與 Spaces 都有頭像＋狀態圓點

- Agents 與 Spaces 兩個檢視的每一列，最前面都是 Agent 種類頭像，**頭像右下角疊狀態圓點**（狀態不再放在名稱前）。
- 原型裡 `agentRow` 的頭像與圓點即此樣式；正式實作沿用 app 現有的 `AgentKindAvatar` 與狀態符號（形狀＋顏色，不只靠顏色）。
