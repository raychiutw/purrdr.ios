# 第一階 tab 版型統一原型(spec #491)

互動原型 `tab-consistency.html`(單檔,瀏覽器直接開;Artifact:https://claude.ai/artifact/C3umsA5T4Gy1tRUEP8NjWW)。
研究報告:`docs/research/tab-consistency-ios26.md`(分支 `docs/tab-consistency-research`)。
本檔依 #491 spec 本文與其「更正(2026-11-23)」段落整理;兩者不一致時以更正段落為準。

## 定案內容
- Podcast 式版型:大標題在左,往下滑搜尋欄收成頂端玻璃膠囊(聊天、檔案),其他 tab 收成置中小標題膠囊。
- 右側:長型玻璃膠囊(電腦圖示｜＋)加頭像圓鈕;＋符號用 `plus`。主機 tab 只有單顆「＋」、流量 tab 只有單顆電腦圖示。
- 檔案 tab 的「＋」只有「上傳檔案」(不做新增資料夾);檔案 tab 也有電腦圖示(標示這頁看哪台主機、點開換主機),但永遠不畫篩選小圓點。聊天、流量選了單一主機時才在電腦圖示右上角畫小圓點。
- 設定併進帳號,帳號是 sheet、右上角 X 關閉;底部四個 tab(聊天、檔案、主機、流量)。
- 帳號 sheet 在後台載入中或連不上時,本機設定(外觀、App 鎖、撤回倒數、終端機大小、關於)照常顯示;會員區顯示載入占位,或「暫時連不上 Purrdr」加「再試一次」。
- 聊天只有 Spaces 檢視(移除 Agents 檢視與切換)。
- 聊天列選 A「郵件式三層」寬鬆版(依 #505,列高 101pt):第一行 Tab 名稱 17pt Semibold(未命名顯示「Tab 2」)＋時間＋用量環、第二行 session 標題 15pt(與 Tab 名相同或空白時省略)、第三行預覽 14pt 次要色;「離開期間」小標籤放第二行開頭。
- 聊天列頭像垂直置中(相對文字內容高度);頭像右下角四色圓點 12px(需要你橘、工作中綠、錯誤紅、其他灰;實心未讀、空心已讀),不用符號。
- Spaces 的 Tab 列長按選單:釘選／取消釘選、靜音／取消靜音、在新視窗開啟(僅 iPad),套用到該 Tab 底下所有 Agent pane。
- 其餘採研究建議:系統單色頂列、小標題膠囊、tab 名稱「聊天」、流量頁保留卡片但邊距對齊。

第 8 區塊「最終定稿」(`v7-s8-*.png`)有標註尺寸,實作以它為準。

## 與實作的已知差異
- 聊天列順序:設計稿與 spec 已改為 Tab 名稱 17pt 在上、session 標題 15pt 在下(#505);實作若仍是 session 標題在上,以此為準修正。
- 檔案頁電腦圖示:設計稿有圖示且永不畫小圓點;原本實作的檔案 tab 沒有主機範圍,需補上。
- 檔案「＋」只有上傳:實作若仍有新增資料夾要移除。
- AX5:設計稿只示意放大行為(右欄堆到文字下方、標題與預覽可折兩行、頂列控制尺寸固定不放大);實際換行點與列高以模擬器驗證為準。
- 未驗證項(研究標「未確認」):Podcast 式捲動的動畫曲線與貼頂位置、頂列字級上限搭配 large content viewer、sheet 關閉鈕的玻璃樣式;設計稿用靜態示意,實作者要在模擬器驗證後回報。
- 設計稿的長按選單與帳號 sheet 是靜態畫面,沒有示意實際動畫與 haptics。
