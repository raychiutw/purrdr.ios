# 第一階 tab 版型統一原型(spec #491)

互動原型 `tab-consistency.html`(單檔,瀏覽器直接開;Artifact:https://claude.ai/artifact/C3umsA5T4Gy1tRUEP8NjWW)。
研究報告:`docs/research/tab-consistency-ios26.md`(分支 `docs/tab-consistency-research`)。

## 使用者已定案
- Podcast 式版型:大標題在左,往下滑搜尋欄收成頂端玻璃膠囊(聊天、檔案),其他 tab 收成小標題膠囊。
- 右側:長型玻璃膠囊(電腦圖示｜＋)加頭像圓鈕;＋符號用 `plus`。
- 檔案 tab 的「＋」只有「上傳檔案」(不含建立資料夾);檔案 tab 也顯示電腦圖示(標示這頁看哪台主機、點開換主機),但永遠不畫篩選小圓點。
- 設定併進帳號,帳號是 sheet、右上角 X 關閉;底部四個 tab(聊天、檔案、主機、流量)。
- 聊天只有 Spaces 檢視(移除 Agents 檢視與切換)。
- 聊天列選 A「郵件式三層」寬鬆版(列高 101pt):第一行 Tab 名 17pt Semibold(未命名顯示「Tab 2」)、第二行 session 標題 15pt(與 Tab 名相同或空白時省略)、第三行預覽;「離開期間」小標籤在第二行開頭。
- 聊天列頭像垂直置中(相對文字內容高度);頭像右下角:四色圓點 12px(需要你橘、工作中綠、錯誤紅、其他灰;實心未讀、空心已讀),不用符號。
- Spaces 的 Tab 列長按選單:釘選／取消釘選、靜音／取消靜音、在新視窗開啟(僅 iPad);套用到該 Tab 底下所有 Agent pane。
- 帳號頁新增「後台載入中」「連不上後台」兩種狀態:會員區顯示載入占位或「暫時連不上 Purrdr」加「再試一次」,本機設定照常顯示。
- 其餘採研究建議:系統單色頂列、主機圖示小圓點、小標題膠囊、tab 名稱「聊天」、流量頁保留卡片但邊距對齊。

第 8 區塊「最終定稿」(`v6-s8-*.png`)有標註尺寸,實作以它為準。
