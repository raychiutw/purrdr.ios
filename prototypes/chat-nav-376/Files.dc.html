Purrdr
在 iPhone 與 iPad 上,看、回覆、操作你電腦上由 herdr 管理的 coding agent。
主要功能
• 所有 Agent 一個列表
• 在聊天裡回答 Agent 的提問
• 需要時開一個完整的終端機
• 直接連到你自己的電腦
安裝
需要 iOS 26 以上。swift test 跑全部測試。
