## 定稿決定(要同步進 DESIGN.md,#378)

- 深色層次:頁面 `#1C1C1E`、卡片與 sheet `#2C2C2E`、sheet 內卡片 `#3A3A3C`。
- 低飽和用量色:正常 深 `#6FAE98`/淺 `#4F8572`、70% 起 深 `#C99A6A`/淺 `#A9784A`、85% 起 深 `#C98078`/淺 `#B0645D`;到門檻加三角形符號。高對比兩組值待 #378 補。
- 深色紅字 `#FF8A82`、淺色 `#D70015`;淺色 tab 選取字 `#075C45`。
- 右上動作依 tab;sheet 左上 xmark 關閉、右上完成;第二層只有對話與終端機隱藏 tab bar;選單用系統 `Menu`:勾與圖示都在文字前(照 iOS 26 系統行為,2026-11-22 修正)。
- 外觀設定保留(偏離 HIG,理由寫進 DESIGN.md)。
- 終端機採 Heeler 做法(#357)。
- 付費牆價格是占位,實作用 StoreKit 在地化價格且比試用字樣醒目。

- 5 個 tab:聊天、檔案、主機、流量、設定(使用者 2026-11-22);「方案用量」維持「用量」,「數據用量」改名「網路流量」並成為流量 tab。

- 帳號與會員(#402,使用者 2026-11-22 確認):舊 `Shell` 帳號畫面由 `AccFlow`/`AccPage`/`AccSub` 取代;獨立審查與研究見 `review/membership-*.md`。
