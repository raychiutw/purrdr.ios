## 畫面

| 檔案 | 內容 |
|---|---|
| `Main` | 聊天輸入區:收合(一列玻璃膠囊)與展開(兩列玻璃卡片、上限 5 行、左右 8pt 貼近鍵盤、模型膠囊「Opus 5.5 中」);無收鍵盤鈕與展開鈕 |
| `Header` | 標題膠囊(52pt、兩行)與點開面板:5 小時／7 天用量、context 圓環、權限模式勾選列 |
| `Menu` | 右上角整合選單:終端機、Git 變更(圖示在前、文字在後) |
| `Model` | 模型選擇 sheet 與投入程度子頁(推薦、3.5× 警示、Ultracode 開關、「會成為新 session 的預設」說明) |
| `Attach` | 加入 sheet:四種檔案類型在最上方、最近的照片(正方形裁切)與已選數量、「加入 N 個」 |
| `Tabs` | 4 個 tab(聊天、檔案、主機、設定);左上 Agents ▾、中間切換主機、右上「+」與帳號同一玻璃容器;聊天列表兩行、狀態在頭像右下角圓章;切換主機選單(不含範例主機) |
| `Host` / `HostHttps` | 主機 tab:SSH 主機(連線、用量、通知、登入 Shell、編輯、刪除)與 HTTPS 主機(主機服務區塊、無用量) |
| `Settings` | 設定 tab(外觀勾選列、用量顯示已用／剩餘、鍵盤與觸覺、其他)與帳號頁(會員、通知裝置) |
| `DarkCompare` | 深色底純黑(現況)vs 提亮(建議) |
| `Files` | 檔案 tab(路徑麵包屑、上傳在路徑列右側)與檔案預覽(第二層,tab bar 隱藏) |
| `Git` | Git 變更清單與單檔 diff |
| `Terminal` | 終端機(深淺模式都是全螢幕深色)與鍵盤展開時的按鍵列 |

## 定稿時的決定(要同步進 DESIGN.md,#378)

- 深色底提亮:頁面 `#1C1C1E`、卡片與輸入框 `#2C2C2E`;sheet 維持系統 elevated。
- 用量與 context 改用低飽和色(與 Agent 頭像同風格):正常 深 `#6FAE98`／淺 `#5E9583`、70% 起 深 `#C99A6A`／淺 `#A9784A`、85% 起 深 `#C98078`／淺 `#B0645D`;取代原「系統橙／系統紅」。實作時補對比測試(非文字圖形 ≥ 3:1)。
- 聊天列表兩行:第一行名稱、主機(次要色)、時間;第二行預覽與 context 圓環;狀態回到頭像右下角圓章(需要你 橙「!」、工作中 主色「•••」、完成 灰「✓」)。
- 選單列一律圖示在前;選項一律勾選列上下攤開(含設定的外觀)。
- 檔案 tab 的上傳移到路徑列右側(右上「+」固定是新增聊天)。
- 設定 tab 中間是標題「設定」,不放切換主機。
