# 聊天畫面降噪與訊息呈現(拋棄式，PROTOTYPE)

- `purrdr-chat-redesign-v1.html`(第 1 版):三種訊息呈現(A 對話泡泡、B 文件式、C 時間軸)× 三種狀態(工作中、需要你、待送＋斷線);點頂列標題開狀態 sheet。`#a-work`、`#b-ask` 之類的 hash 切換。

問題(使用者，2026-11-21):聊天被太多狀態打擾;權限與模型放進輸入框;輸入框寬度沒對齊;訊息呈現缺設計感(參考外部 AI 聊天工具);Markdown、程式碼、表格、圖檔縮圖、檔案卡片一起設計。

三版共通(使用者已同意的降噪原則，grill Q10):頂列一行狀態＋狀態 sheet;對話區只放對話(步驟收成一行);輸入列上方只留工作中膠囊(含子 Agent 數);待送訊息同一種虛線泡泡;錯誤集中一條橫幅;輸入框內：＋附加、模型、權限模式、送出。

- `purrdr-chat-redesign.html`(第 2 版):以 A 為基礎、依 HIG 加強液態玻璃的三種版本(A1 浮動膠囊、A2 玻璃列、A3 沉浸)。

## 結論

- 第 1 版選 **A 對話泡泡**,要求參考 HIG 加強液態玻璃、讓聊天可視區域變大，並以 A 重新給三版(第 2 版)。Liquid Glass 規範已寫進整合分支的 DESIGN.md。
- 第 2 版：**A1 浮動膠囊** 定稿(2026-11-21):返回鈕、標題、工作中膠囊、輸入框各自是浮在內容上的玻璃膠囊，上下漸層淡出，訊息從底下捲過去;模型與權限是輸入框裡的兩個 chip,左邊「＋」附加、右邊送出。

## 附加(「＋附加」,2026-11-21)

- `purrdr-attach.html`:以 A1 輸入框為底的三種附加做法(1 系統選單、2 底部面板、3 展開圓鈕)× 點了＋、已選 3 個、iPad 拖進來。`#v1-open` 之類的 hash 切換。
- 共通(使用者同意，grill Q11):「＋」VoiceOver 念「附加」;照片圖庫、拍照、檔案、貼上;任何檔案類型、可多選、單檔 25 MiB;送出前的附件小卡可個別移除;iPad 拖放。
- 結論：**2 底部面板**(2026-11-21 使用者選定):點「＋」升起面板，上方最近的照片可直接多選，下方相機、所有照片、檔案、貼上四顆大按鈕;附件在輸入框裡排成小卡。讀最近的照片需要相簿權限(支援系統的有限存取;沒給權限時面板只顯示四顆按鈕)。
